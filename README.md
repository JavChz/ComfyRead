# ComfyRead 📖

A minimalist, distraction-free text area designed for comfortable reading. Ideal for copying and pasting text from poorly formatted or visually cluttered documents so you can read them in a clean, easily digestible layout.

[**Live Demo**](https://javchz.github.io/ComfyRead/)

## ✨ Features

- **Distraction-Free Reading:** A clean, uncluttered interface focused entirely on the content.
- **Light & Dark Mode:** Warm-toned aesthetics with a manual toggle to suit your reading environment.
- **Customizable Layout:** Switch to a 'Compact' layout that aligns content for a more focused reading experience.
- **Beautiful Typography:** Uses the clean and highly readable *Lexend* font.
- **Responsive Design:** Looks beautifully minimal on desktop and mobile browser.

## 🛠️ Built With

- [React 19](https://react.dev/)
- [Vite 8](https://vitejs.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)

## 🚀 Getting Started

To run this project locally, follow these steps:

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/javchz/ComfyRead.git
   ```
2. Navigate into the project directory:
   ```bash
   cd ComfyRead
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

To start the development server:
```bash
npm run dev
```

### Build

To create a production-ready build:
```bash
npm run build
```

### Deploy (GitHub Pages)

To build and deploy the app to GitHub pages:
```bash
npm run deploy
```
